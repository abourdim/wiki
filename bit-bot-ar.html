نظرة عامة

Bit-Bot هو تطبيق ويب بدون تثبيت، ملف HTML واحد: وجه روبوت متحرك تتحدث معه بالصوت أو النص، يجيب باستخدام مزوّد ذكاء اصطناعي من اختيارك (أو وضع عرض تجريبي دون اتصال بالإنترنت تمامًا). يقترن اختياريًا بـ BBC micro:bit عبر Web Bluetooth، ليعكس المشاعر والأوامر على شاشة LED مقاس 5×5 الخاصة بالـ micro:bit ويقرأ حساساته أثناء الألعاب.

التطبيق بأكمله — الواجهة، نظام الترجمة، استدعاءات الذكاء الاصطناعي، إدارة البلوتوث — يعيش في ملف index.html واحد، بالإضافة إلى صفحة flash.html منفصلة للحصول على فيرموير الـ micro:bit المرافق، وبضعة ملفات microbit_makecode_*.js تحتوي على الكود المصدري لذلك الفيرموير.

البدء السريع

  1. افتح التطبيق المباشر في Chrome أو Edge (واجهات Web Bluetooth وSpeech مطلوبتان، لذا لن يعمل Safari/Firefox بشكل كامل).
  2. مرّ بخطوات التهيئة الأربع: سمِّ روبوتك، اختر شخصية، وصِل micro:bit اختياريًا.
  3. اضغط على الميكروفون 🎤 أو اكتب رسالة، ثم أرسل. يجيب الروبوت في فقاعة الدردشة وينطقها بصوت عالٍ.

خطوة بخطوة: الاستنساخ والتحميل والاختبار

يأخذك هذا الدليل من نسخة فارغة إلى روبوت يعمل بشكل كامل — دردشة نصية وصوتية، و(اختياريًا) micro:bit مقترن — دون افتراض أي شيء سوى تثبيت Chrome أو Edge.

1. استنساخ المستودع

git clone https://github.com/abourdim/bit-bot.git
cd bit-bot

2. تشغيل الموقع محليًا

لا توجد خطوة بناء — إنه HTML/CSS/JS خالص — لكن واجهتَي Web Speech وWeb Bluetooth ترفضان العمل من مسار file:/// مباشر، لذا شغّل المجلد عبر HTTP:

python3 -m http.server 8000

ثم افتح http://localhost:8000 في Chrome أو Edge.

3. الحصول على فيرموير الـ micro:bit (اختياري)

تخطَّ هذه الخطوة تمامًا إذا كنت تريد فقط اختبار الدردشة النصية/الصوتية. وإلا، افتح flash.html، اضغط نسخ كود micro:bit، الصقه في تبويب JavaScript لمشروع جديد على makecode.microbit.org، أضف إضافة bluetooth، اضبط إعدادات المشروع ← «لا حاجة للاقتران»، وحمّله على اللوحة.

4. اختبار الدردشة النصية

بدون تهيئة مفتاح API، يعمل التطبيق تلقائيًا في وضع 🎮 العرض التجريبي — اكتب رسالة واضغط إرسال؛ يجب أن تحصل على رد معدّ مسبقًا لكنه يناسب الشخصية، دون أي اتصال بالشبكة إطلاقًا. هذا يؤكد أن الواجهة وآلة الحالة تعملان قبل إشراك أي مزوّد ذكاء اصطناعي حقيقي.

5. اختبار الصوت

اضغط زر 🎤، اسمح بالميكروفون، وتحدث. التشغيل السليم يُظهر النص المكتوب، ثم ردًا منطوقًا مع تحرك فم/عيني الروبوت أثناء الحديث.

6. اختبار الاتصال بالـ micro:bit

اضغط شارة الاتصال في الترويسة، اختر لوحتك من منتقي أجهزة البلوتوث، وانتظر وجهًا سعيدًا — على الشاشة وعلى شبكة LED الخاصة بالـ micro:bit نفسها. إذا لم يظهر أبدًا، راجع حل المشكلات.

7. اختبار لعبة

افتح لوحة 🎮 وابدأ Smart Tilt Quiz. حتى بدون مفتاح ذكاء اصطناعي ودون اتصال بـ micro:bit، يجب أن يطرح سؤالًا من بنك الاحتياط المدمج (اضغط تسميات A/B على الشاشة، أو أمِل الـ micro:bit إن كان مقترنًا) — مؤكدًا أن منطق اللعبة والمحتوى الاحتياطي يعملان بشكل مستقل عن أي اتصال بالشبكة.

يبدو الأساس الناجح كالتالي: ردود في وضع العرض التجريبي بدون مفتاح، صوت في الاتجاهين، وجه سعيد على الـ micro:bit بعد الاقتران، وسؤال اختبار يمكنك الإجابة عليه بأي طريقة. فقط بعد أن يعمل كل هذا يستحق الأمر حل مشكلات مفتاح مزوّد ذكاء اصطناعي معيّن.

فهم الكود (للمبتدئين)

هذا القسم لمن لديه التطبيق قيد التشغيل ويريد فتح index.html والبدء بتعديل شيء ما. يفترض معرفة أساسية بـ JavaScript لكن لا معرفة مسبقة بهذا الكود. تخطَّه تمامًا إذا كنت تريد فقط استخدام التطبيق.

شكل الملف

كل شيء — البنية، CSS، وJavaScript — يعيش في ملف index.html واحد، يمتد لآلاف الأسطر، في ثلاث كتل: كتلة <style>، جسم HTML (الترويسة، بطاقة التهيئة، واجهة الدردشة، لوحة الإعدادات، نافذة المساعدة، لوحات الألعاب/الأوامر)، وكتلة <script> كبيرة في النهاية بدون نظام وحدات — كل دالة هي تصريح function بسيط من المستوى الأعلى، يمكن استدعاؤها مباشرة من سمات onclick="..." المضمّنة في HTML.

كائن state

كائن واحد بسيط يحمل كل ما يحتاج للاستمرار أو لدفع الواجهة: حالة الاتصال، مزوّد الذكاء الاصطناعي الحالي ومفاتيحه، اسم الروبوت وشخصيته، سجل الدردشة لكل شخصية، وتفضيلات الواجهة مثل اللغة والسمة. يُحفظ في localStorage كـ JSON عند كل تغيير ذي صلة (saveSettings()) ويُستعاد عند التحميل (loadSettings()) — لا توجد طبقة استمرارية أخرى.

نظام الترجمة: I18N ← tr() ← data-i18n

كل نص يظهر للمستخدم يعيش في كائن I18N مفهرس حسب اللغة (en/fr/ar)، ثم بمفتاح قصير:

const I18N = {
  en: { onb_welcome_title: "Welcome!", ... },
  fr: { onb_welcome_title: "Bienvenue !", ... },
  ar: { onb_welcome_title: "مرحباً!", ... }
};
function tr(key) { return I18N[state.lang][key] ?? I18N.en[key] ?? key; }
function trg(key, vars) { /* tr() plus {placeholder} substitution */ }

عناصر HTML الثابتة مُعلَّمة بـ data-i18n="onb_welcome_title"؛ تمرّ applyLang(lang) على كل عنصر معلَّم وتضبط نصه من tr(). النصوص الديناميكية (الإشعارات، أسطر السجل، سرد ألعاب الذكاء الاصطناعي) تستدعي tr()/trg() مباشرة من JavaScript. تغيير اللغة هو استدعاء دالة واحد، setLanguage(lang)، الذي يعيد تشغيل applyLang() ويحفظ الاختيار.

كيف تتدفق رسالة الدردشة: إدخال المستخدم ← الذكاء الاصطناعي ← الروبوت

  user types/speaks
       │
       ▼
  sendMessage()  ──▶  addBubble('user', text)
       │
       ▼
  callAI(text)  ──▶  branches on state.provider:
       │                     Demo → getDemoResponse() (canned, offline)
       │                     Groq / Gemini / Cohere / Mistral / OpenRouter
       │                       → fetch() to that provider's REST API
       ▼
  parse reply, strip [command] tags
       │
       ▼
  addBubble('robot', text)  +  speak(text)  +  sendCommand(emotion)

ينتهي موجّه النظام الخاص بالذكاء الاصطناعي دائمًا بتوجيه لغوي مبني من tr('ai_lang_directive')، حتى يجيب النموذج نفسه بلغة الواجهة المختارة حاليًا بدلًا من ترجمة نص الواجهة الثابت فقط. تُحدّث sendCommand() الوجه المعروض على الشاشة، وإذا كان الـ micro:bit متصلًا، تكتب نفس الأمر عبر البلوتوث.

التحدث إلى micro:bit: connect()، sendCommand()، handleRx()

تستدعي connect() الدالة navigator.bluetooth.requestDevice() مُصفّاة على خدمة Nordic UART، ثم تكتشف خاصيتَي TX (إشعار، من micro:bit إلى المتصفح) وRX (كتابة، من المتصفح إلى micro:bit). كل أمر صادر — مشاعر، إدخال لعبة، حركة محرك — يمر عبر دالة واحدة، sendCommand(cmd)، التي تكتبه كسطر UTF-8 إلى خاصية RX. كل ما يرسله الـ micro:bit للخلف (ضغطات الأزرار، قراءات الحساسات) يصل كحدث characteristicvaluechanged تعالجه handleRx()، التي تحلّل السطر وتوجّهه — مثلًا إلى processScienceReading() أثناء لعبة المحقق العلمي.

آلة حالة التهيئة

التهيئة هي أربع بطاقات HTML، واحدة فقط ظاهرة في كل مرة، تُدار بعدد صحيح واحد currentOnboardingStep. تكتفي nextOnboardingStep()/prevOnboardingStep() بزيادته/إنقاصه وتبديل أي بطاقة تحمل فئة .active؛ تضبط completeOnboarding() القيمة state.onboardingComplete = true، تحفظها، وتخفي كامل الطبقة العلوية حتى لا تظهر مجددًا أبدًا على هذا المتصفح.

معمارية النظام، بالرسم التوضيحي

رحلتا ذهاب وإياب مستقلتان واختياريتان تلتقيان في منتصف تبويب متصفح واحد — استدعاء الذكاء الاصطناعي ورابط micro:bit لا يتحدثان أبدًا مباشرة، فقط عبر حالة التطبيق نفسها:

                        ┌─────────────────────────┐
                        │   index.html (browser)  │
                        │  ─────────────────────  │
   🎤 mic / ⌨ keyboard ─▶│  sendMessage()          │
                        │       │                 │
                        │       ▼                 │
   AI provider API   ◀──▶  callAI(text)           │
   (Groq/Gemini/...)     │       │                 │
                        │       ▼                 │
                        │  addBubble()+speak()    │
                        │       │                 │
                        │       ▼                 │
   BBC micro:bit     ◀──▶  sendCommand(emotion)   │
   (Bluetooth LE)        │  handleRx() ◀── sensors│
                        └─────────────────────────┘

ساق الذكاء الاصطناعي هي HTTP عبر واي فاي/بيانات (تُتخطى تمامًا في وضع العرض التجريبي)؛ ساق micro:bit هي Bluetooth LE، تُقترن مرة واحدة لكل جلسة متصفح. يمكن أن تغيب أي منهما — التطبيق قابل للاستخدام الكامل بدون أي منهما، أو بواحدة، أو بكلتيهما متصلتين.

تخطيط HTML، بالرسم التوضيحي

داخل <body>، البنية هي كومة مسطحة من الطبقات المعروضة/المخفية بشكل مستقل، بالإضافة إلى شاشة الدردشة الظاهرة دائمًا في الأسفل:

  <body>
   ├─ #onboarding        first-run wizard, 4 cards, one .active at a time
   ├─ #helpOverlay        ❓ quick-reference modal
   ├─ header              lang flags · robot/AI badges · connect · firmware · help · ☰
   ├─ main                robot face + chat bubbles + text/mic input
   ├─ #settingsPanel      slide-in: Fun / Setup / Advanced tabs
   ├─ #commandsPanel      📋 quick-command cheat sheet, by category
   └─ #gamesPanel         🎮 Smart Tilt Quiz / Adventure / Science Detective

كل واحدة من هذه اللوحات/الطبقات هي مجرد <div> تبدّل فئة CSS .open (أو .active) عبر دالة صغيرة toggleX() — لا يوجد توجيه، ولا DOM افتراضي، ولا إطار عمل. يحتوي <head> كتلة <style> واحدة كبيرة مضمّنة بخصائص CSS مخصصة (--primary، --surface، إلخ) يُعيد [data-theme="dark"] تعريفها — هذا هو نظام السمات بأكمله.

فيرموير الـ micro:bit: microbit_makecode_v3.js

هذا هو البرنامج الذي تحمّله على اللوحة نفسها — عالم منفصل، أصغر بكثير من تطبيق الويب، مكتوب بلهجة JavaScript/TypeScript الخاصة بـ MakeCode. ليس لديه أي مفهوم عن «الذكاء الاصطناعي» أو «الدردشة»؛ كل ما يعرفه هو مفردات مسطحة من أوامر نصية بكلمة واحدة تصل عبر Bluetooth UART، وكيفية التفاعل مع كل منها على شبكة LED مقاس 5×5.

صور LED مجرد نص

كل وجه/أيقونة هو استدعاء images.createImage() على شبكة 5×5 من . (مطفأ) و# (مضاء):

const HAPPY = images.createImage(`
    . . . . .
    . # . # .    ← eyes
    . . . . .
    # . . . #
    . # # # .    ← smile
    `)

يوجد 15 من هذه الصور النقطية في الملف — مشاعر (HAPPY، SAD، ANGRY، SURPRISED، LOVE، SLEEPY، SILLY، WOW، HAHA، COOL)، حيوانان (CAT، DOG)، وخمس أيقونات ألعاب (أسهم، علامة استفهام، علامة صح، علامة خطأ، ميزان حرارة، مصباح). تريد وجهًا جديدًا؟ انسخ نمط النقاط والمربعات لأي وجه موجود وغيّر الشكل — لا شيء آخر في الملف يحتاج لمعرفته حتى تضيفه أيضًا إلى معالج الأوامر أدناه.

إبقاء مرآة LED في المتصفح متزامنة

في كل مرة يغيّر فيها الـ micro:bit ما يعرضه، يبث أيضًا شبكة الـ25 بكسل كاملة عبر البلوتوث كسطر نصي واحد، وهذا ما يشغّل أداة مرآة LED ⚫ في تطبيق الويب:

function sendLEDState() {
    let state = "LED:"
    for (let y = 0; y < 5; y++)
        for (let x = 0; x < 5; x++)
            state += led.point(x, y) ? "1" : "0"
    bluetooth.uartWriteString(state + "\n")
}
function showAndSync(img: Image) {
    img.showImage(0)
    basic.pause(50)   // let the image actually latch before reading it back
    sendLEDState()
}

تستدعي كل الرسوم المتحركة تقريبًا showAndSync() بدلًا من showImage() الخام من MakeCode، خصيصًا حتى لا تنحرف مرآة المتصفح أبدًا عن اللوحة الفعلية.

جدول توزيع الأوامر

دالة واحدة، handleCommand(cmd)، تستقبل كل سطر يرسله المتصفح وتمرره عبر سلسلة if / else if طويلة تُقارن حرفيًا بأحرف صغيرة — لا يوجد JSON، ولا بروتوكول منظم، فقط كلمات بسيطة:

الأمر/الأوامرما يحدث على اللوحة
happy, sad, angry, surprised/wow, love, sleepy, silly, haha, cool, cat, dogيعرض الوجه/الأيقونة الثابتة المطابقة.
wave, dance, spin, party, magicيشغّل رسمًا متحركًا قصيرًا متعدد الإطارات، ثم يستقر على HAPPY.
quiz / correct,yes / wrong,no / thinkingوجوه حالة اللعبة: علامة استفهام، صح + احتفال، خطأ + حزن، أيقونة «حائر».
read_temp / read_lightيعرض أيقونة، يقرأ الحساس الحقيقي بـ input.temperature()/input.lightLevel()، يرسله للخلف كـ TEMP:<n>/LIGHT:<n>، ويعرض الرقم على LED.
left/right/forward/backward, count, dice, rainbowمرئيات ألعاب/أدوات متنوعة (أسهم، عد من 1 إلى 5، رمي نرد عشوائي، قوس قزح وامض على كامل الشبكة).
أي شيء غير معروفيعرض علامة استفهام QUESTION — الفيرموير لا يتعطل أبدًا عند كلمة غير معروفة.

استشعار العالم: الإمالة، الاهتزاز، الأزرار

ثلاثة مصادر إدخال تعمل بشكل مستقل عن معالج الأوامر ولا تفعل سوى إرسال البيانات، لا استقبالها أبدًا — هكذا تحصل الألعاب في المتصفح على إدخال حساس حقيقي:

basic.forever(function () {   // polled every loop, ~cooldown-gated
    let x = input.acceleration(Dimension.X)
    if (x < -TILT_THRESHOLD) bluetooth.uartWriteString("TILT_LEFT\n")
    else if (x > TILT_THRESHOLD) bluetooth.uartWriteString("TILT_RIGHT\n")
})
input.onGesture(Gesture.Shake, function () {
    bluetooth.uartWriteString("SHAKE\n")
})
input.onButtonPressed(Button.A, function () {
    bluetooth.uartWriteString("BTN_A\n")
    // ...also shows an icon locally
})

فترة تهدئة مشتركة INPUT_COOLDOWN (500 مللي ثانية) وطوابع زمنية لـ«آخر إطلاق» لكل إدخال تمنع إمالة أو اهتزازًا فعليًا واحدًا من إغراق أحداث مكررة متعددة — نفس فكرة إزالة الارتداد المستخدمة في آلية الأمان بـ500 مللي ثانية في مشروع VideoCar الشقيق، لكن مطبَّقة على الإيماءات بدلًا من أوامر المحرك.

أول تشغيل: التهيئة

يرى الزوار الجدد بطاقة تهيئة من 4 خطوات قبل التطبيق الرئيسي:

الخطوةما يحدث
1. الترحيبمقدمة عن الميزات الرئيسية الثلاث: الدردشة الصوتية، micro:bit، الشخصيات.
2. التخصيصاكتب اسم روبوت واختر واحدة من 12 شخصية.
3. توصيل الـ Micro:bitاقتران بلوتوث اختياري، أو «تخطَّ الآن».
4. اكتمل كل شيءبطاقة نصيحة، ثم «ابدأ الدردشة» يأخذك إلى التطبيق الرئيسي برسالة ترحيب منطوقة.

يُحفظ الاكتمال في localStorage، لذا تعمل التهيئة مرة واحدة فقط لكل متصفح.

اسم الروبوت & الشخصية

الشخصيات المتاحة: مرحة (افتراضي)، مفيدة، قرصان، فضائية، بطل، دينو، جنية، نينجا، ساحر، راعي بقر، غريب فضائي، حورية بحر. لكل منها نبرة موجّه نظام خاصة بها وسجل دردشة منفصل خاص بها (حتى آخر عدة رسائل لكل شخصية)، لذا تغيير الشخصية لا يفقد المحادثة التي كنت تجريها مع أخرى.

اسم الروبوت قابل للتعديل في أي وقت من الإعدادات (☰) ← Fun. يُحفظ حقل الاسم عند كل ضغطة مفتاح (وليس فقط عند فقدان التركيز) ويعرض إشعار تأكيد، لذا لا يمكنه أبدًا الفشل في الحفظ بصمت.

كل موجّه ذكاء اصطناعي — الدردشة الرئيسية والألعاب المصغرة الثلاث — له توجيه لغوي مُضاف حسب لغة الواجهة المختارة حاليًا، حتى تعود ردود النموذج المولَّدة نفسها بالإنجليزية أو الفرنسية أو العربية بدلًا من ترجمة نص الواجهة الثابت فقط.

توصيل micro:bit

اضغط شارة الاتصال في الترويسة (أو أثناء الخطوة 3 من التهيئة) للاقتران عبر Web Bluetooth. بمجرد الاتصال، تنعكس مشاعر الروبوت وأوامره المنطوقة مباشرة على شبكة LED مقاس 5×5 الخاصة بالـ micro:bit، ويمكن لمقياس التسارع/الأزرار/الحساسات الخاصة بالـ micro:bit تشغيل الألعاب (انظر أدناه).

يتطلب Web Bluetooth سياقًا آمنًا: https:// أو localhost. لن يعمل عند فتحه كملف HTML مباشر file:///.

الحصول على كود الفيرموير

يحتاج جانب micro:bit إلى برنامج MakeCode صغير يُحمَّل مرة واحدة. بدلًا من إرسال الناس إلى GitHub لنسخ الكود المصدري الخام يدويًا، flash.html هي صفحة مخصصة:

  • تجلب microbit_makecode_v3.js الحالي عند التحميل وتعرضه في كتلة كود قابلة للتمرير.
  • تحتوي زرًا كبيرًا واحدًا نسخ كود micro:bit (واجهة الحافظة مع بديل execCommand).
  • تسرد الخطوات الست للصقه في makecode.microbit.org، إضافة إضافة bluetooth، تفعيل «لا حاجة للاقتران»، والتحميل.

اللغات & نظام الترجمة

الواجهة، وكل رسائل الإشعارات/الحالة/السجل، وكل سرد الألعاب مترجمة بالكامل إلى الإنجليزية والفرنسية والعربية (مع تخطيط من اليمين إلى اليسار للعربية) عبر كائن I18N مدمج ودوال مساعدة tr()/trg() مفهرسة بسمات data-i18n. الفرنسية هي اللغة الافتراضية. يوجد منتقي قائم على الأعلام في الترويسة؛ يُحفظ الاختيار في localStorage.

المساعدة داخل التطبيق

يفتح زر ❓ في الترويسة نافذة مرجعية سريعة (تحدث مع روبوتك، الاسم & الشخصية، توصيل micro:bit، الأوامر & الألعاب، نصائح)، مترجمة مثل بقية الواجهة. تُغلق عبر زر ×، مفتاح Escape، أو النقر خارج البطاقة.

الخصوصية بالتصميم: في وضع العرض التجريبي، لا شيء يغادر المتصفح. في أي وضع ذكاء اصطناعي آخر، تُرسَل فقط رسائلك المكتوبة/المنطوقة إلى واجهة برمجة ذلك المزوّد — الإعدادات، اسم الروبوت، وسجل الدردشة تبقى في localStorage فقط.

البيانات & الخصوصية

  • يعمل وضع العرض التجريبي دون اتصال بالإنترنت تمامًا.
  • ترسل أوضاع الذكاء الاصطناعي رسائلك إلى خوادم المزوّد المختار (Groq/Google/Cohere/Mistral/OpenRouter).
  • تُخزَّن الإعدادات واسم/شخصية الروبوت وسجل الدردشة فقط في localStorage الخاص بالمتصفح — لا شيء يُرفع في أي مكان آخر.
  • لا تحليلات، لا سكربتات تتبّع.
