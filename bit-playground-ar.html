نظرة عامة

micro:bit Playground لوحة تحكم قائمة على الويب لـ BBC micro:bit V2 عبر البلوتوث منخفض الطاقة: ثمانية تبويبات تغطي التحكم بـLED/النص/الجرس، قراءات حساسات حية مع رسوم صغيرة، قناتا سيرفو، لوحة اتجاه على طراز ذراع التحكم، رسم بياني حي بـChart.js مع تسجيل/إعادة تشغيل/تصدير CSV، خمسة نماذج روبوت ثلاثية الأبعاد تفاعلية بـThree.js متزامنة مع بيانات حساسات حقيقية، مختبر أوامر خام للخبراء، وتبويب «المزيد» المتنوع من الأدوات الإضافية (عصا تحكم، لوحة مفاتيح، لوحة XY، تحكم بالمنافذ، والمزيد). على عكس شقيقيه الأبسط (Bit-Bot، Talking Robot)، ليس له أي مزوّد ذكاء اصطناعي ولا أي ميزات صوتية إطلاقًا — تركيزه بالكامل هو تحويل كل حساس ومخرج في micro:bit إلى شيء يمكنك رؤيته ورسمه بيانيًا وتشغيله من المتصفح.

وهو أيضًا الأنضج معماريًا من الثلاثة: بدلًا من <script> واحد ضخم مضمّن، ينقسم JavaScript إلى تسعة ملفات مركّزة تحت js/، مُحمّلة بترتيب اعتماد ثابت، بالإضافة إلى خمسة ملفات أخرى تحت js/models/ للروبوتات ثلاثية الأبعاد.

البدء السريع

  1. حمّل makecode.ts على BBC micro:bit V2 عبر makecode.microbit.org (انظر الحصول على الفيرموير).
  2. افتح التطبيق المباشر في Chrome أو Edge.
  3. اضغط اتصال واختر micro:bit الخاص بك من منتقي أجهزة البلوتوث — تتحول شارة الحالة إلى الأخضر بمجرد الاتصال.
  4. استكشف التبويبات الثمانية (أو اضغط 1–8 للانتقال مباشرة إلى أحدها).

خطوة بخطوة: الاستنساخ والتحميل والاختبار

يأخذك هذا الدليل من نسخة فارغة إلى لوحة تحكم مُتحقَّق من عملها: حساسات تتحدث حيًّا، LED قابلة للتحكم، ونموذج ثلاثي الأبعاد يتحرك بتزامن.

1. استنساخ المستودع

git clone https://github.com/abourdim/bit-playground.git
cd bit-playground

2. تحميل الفيرموير

افتح makecode.microbit.org، أنشئ مشروعًا، انتقل إلى تبويب JavaScript، الصق محتوى makecode.ts، ثم نزّله وحمّله على micro:bit V2 الخاص بك. شغّله عبر USB أو بطاريات — يعرض أيقونة X بمجرد أن يبدأ البث عبر البلوتوث وينتظر اتصالًا.

3. تشغيل التطبيق محليًا

لا حاجة لخطوة بناء، لكن Web Bluetooth يرفض مسار file:/// مباشرًا:

npm run serve

(غلاف بسيط حول npx serve .، موجود بالفعل في package.json) وافتح رابط http://localhost:... المعروض في Chrome أو Edge. النسخة المباشرة على GitHub Pages تعمل بنفس الطريقة دون أي إعداد محلي.

4. الاتصال وتأكيد القياس عن بُعد

اضغط اتصال، اختر لوحتك. في تبويب الحساسات، يجب أن تبدأ الحرارة/الضوء/الصوت/مقياس التسارع/البوصلة جميعها بالتحديث خلال ثانية، كل منها برسم صغير حي خاص به.

5. اختبار مخرج: مصفوفة LED

في تبويب التحكم، اضغط بضع خلايا في شبكة 5×5، أو المس الإعداد المسبق ❤️ قلب، وتأكد من تطابق LED الفعلية على اللوحة مع ما هو مرسوم على الشاشة.

6. اختبار نموذج ثلاثي الأبعاد

افتح تبويب اللوحة ثلاثية الأبعاد، اختر نموذج micro:bit V2، وأمِل اللوحة الفعلية — يجب أن يميل النموذج ثلاثي الأبعاد ليطابق خلال جزء من الثانية، ويجب أن تعكس LED الخاصة به أي نمط معروض حاليًا.

7. اختبار الرسم البياني دون الحاجة لتغيير الفيرموير

في تبويب الرسم البياني، اضغط 🎲 محاكاة — يبدأ الفيرموير في بث بيانات جيبية/عشوائية/متدرجة اصطناعية كل 200 مللي ثانية دون أي حساس أو توصيل — وهي أسرع طريقة لتأكيد أن خط أنابيب BLE←رسم بياني بأكمله يعمل قبل الوثوق بقراءة حساس حقيقية.

يبدو الأساس الناجح كالتالي: خمسة رسوم صغيرة حية للحساسات، نقرات LED تنعكس فورًا على اللوحة الفعلية، النموذج ثلاثي الأبعاد يميل مع اللوحة الحقيقية، ورسم بياني متحرك في وضع المحاكاة — كل هذا قبل حتى أن تلمس سيرفو أو ذراع التحكم أو تبويب المزيد.

فهم الكود (للمبتدئين)

لمن لديه التطبيق قيد التشغيل ويريد فتح الكود المصدري والبدء بتعديل شيء ما. يفترض معرفة أساسية بـJavaScript لكن لا شيء خاص بهذا الكود تحديدًا. تخطَّه إذا كنت تريد فقط استخدام التطبيق.

تخطيط وحدات JS وترتيب التحميل

تسعة ملفات تحت js/، مُحمّلة عبر وسوم <script> مؤجلة بسيطة بترتيب ثابت لأن الملفات اللاحقة تفترض أن السابقة قد عملت بالفعل:

#الملفالمسؤولية

4sensors.jsيحلل أسطر القياس عن بُعد، يحدّث واجهة الحساسات + الرسوم الصغيرة، يغذّي الرسم البياني والثلاثي الأبعاد.
5controls.jsمصفوفة LED، الجرس، تبديل التبويبات، المختبر، منتقي السمة، تهيئة الصفحة.

لا يوجد مجمّع ولا نظام وحدات (لا import/export) — كل ملف يعلن ببساطة دوالًا ومتغيرات من المستوى الأعلى تقرأها السكربتات اللاحقة مباشرة، لذا ترتيب الملفات في index.html هو رسم الاعتمادية.

الإرسال إلى micro:bit: sendLine() والتجزئة

كل أمر صادر يمر عبر دالة واحدة في ble.js:

const BLE_MTU_PAYLOAD = 20; // typical BLE ATT payload limit

function sendLine(line) {
    const data = new TextEncoder().encode(line + '\n');
    if (data.byteLength <= BLE_MTU_PAYLOAD) {
        writeChar.writeValue(data);          // fits in one write
    } else {
        // split into 20-byte pieces, write sequentially via a Promise chain
        // so a long command (e.g. a long TEXT: string) can't corrupt mid-flight
    }
}

إعادة الاتصال التلقائي آلة حالة صغيرة: حتى MAX_RECONNECT_ATTEMPTS (3) محاولات، بفاصل RECONNECT_DELAY_MS (2000 مللي ثانية)، متتبَّعة بعدّاد reconnectAttempts وعلامة userDisconnected — هذه العلامة هي ما يمنع التطبيق من مقاومة نقرة قطع اتصال متعمدة بمحاولة إعادة الاتصال فورًا.

نظام i18n: lang.js وt()

1389 سطرًا، تقريبًا بالكامل كائن LANG كبير واحد مفهرس en/fr/ar، كل منها قاموس مسطح من مفاتيح نصية (app_title، connect_btn، وعشرات أخرى). يستدعي كل ملف آخر t(key) عامًا واحدًا للبحث عن نص اللغة النشطة، مع الرجوع للإنجليزية إذا كان المفتاح مفقودًا في اللغة الحالية — نفس نمط tr() المستخدم في Bit-Bot وTalking Robot، تم التوصل إليه بشكل مستقل لنفس السبب: دالة بحث واحدة، مصدر حقيقة واحد، سهل البحث فيه (grep) عن المفاتيح المفقودة. يعيد زر العلم العربي استخدام نفس SVG العلم الجزائري الدقيق (نصفان أخضر/أبيض، هلال ونجمة حمراوان) المستخدم في التطبيقين الآخرين من هذه المجموعة.

فيرموير الـ micro:bit: أوامر مطابقة بالبادئة

مع أكثر من 30 أمرًا مختلفًا، لا يستخدم هذا الفيرموير سلسلة طويلة واحدة من فحوصات if (cmd == "...") بمطابقة دقيقة كالفيرموير الأبسط للتطبيقات الشقيقة — بل يطابق حسب البادئة، لأن معظم الأوامر تحمل معاملًا بعد نقطتين:

bluetooth.onUartDataReceived(serial.delimiters(Delimiters.NewLine), function () {
    let line = bluetooth.uartReadUntil(serial.delimiters(Delimiters.NewLine)).trim()
    bluetooth.uartWriteLine("ECHO:" + line)        // every line is echoed for debugging

    if (line.substr(0, 5) == "TEXT:") { basic.showString(line.substr(5)); return }
    if (line.substr(0, 3) == "LM:")   { handleLedMatrixHex(line.substr(3)); return }
    if (line.substr(0, 4) == "TAB:")  { currentTab = line.substr(4).toLowerCase(); ... return }
    if (line == "SERVO1:OFF")         { pins.analogWritePin(AnalogPin.P1, 0); ... return }
    // ...continues for SERVO1:<angle>, SERVO2:*, BUZZ:*, CMD:*, OTHER:*, BENCH:*, JSON:*, ...
})

كل فرع يقوم بـreturn فورًا عند التطابق، لذا تتصرف القائمة كجدول بحث رغم أنها مكتوبة كـif متسلسلة — الترتيب لا يهم غالبًا لأن كل بادئة فريدة.

فك ترميز مصفوفة LED: LM:<hex10>

يرمّز المتصفح شبكة 5×5 بأكملها إلى 10 أحرف سداسية عشرية (بايت واحد لكل صف، 5 صفوف)، ويفكّ الفيرموير ترميزها بت تلو الآخر:

function handleLedMatrixHex(hex2: string) {
    if (hex2.length != 10) { bluetooth.uartWriteLine("LOG:LM_BAD_LENGTH:" + hex2.length); return }
    for (let row = 0; row <= 4; row++) {
        let value = hexPairToByte(hex2.substr(row * 2, 2))   // "1F" → 31
        for (let col = 0; col <= 4; col++) {
            const mask = 1 << col
            if ((value & mask) != 0) led.plot(col, row)
            else led.unplot(col, row)
        }
    }
    bluetooth.uartWriteLine("LOG:LM_OK:" + hex2)
}

تتطابق البتات الخمس المنخفضة لكل بايت صف واحدًا لواحد مع أعمدة LED الخمسة في ذلك الصف عبر قناع بتات — نفس الترميز الذي يستخدمه سطر القياس عن بُعد LEDS:<r0>,<r1>,<r2>,<r3>,<r4> بالعكس لإبلاغ حالة LED للمتصفح كي يعكسها النموذج ثلاثي الأبعاد.

ضوابط تعارض المنافذ

يشترك السيرفو والجرس في منافذ فعلية مع حساسات اللمس (P1/P2/P0). بدلًا من تركهما يتصارعان، يضبط الفيرموير علامة منطقية (servo1Active، servo2Active، buzzerActive) كلما استُخدمت تلك الميزة، وتتحقق حلقة استطلاع اللمس من العلامة قبل القراءة — إرسال SERVO1:OFF يمسح العلامة ويعيد المنفذ لاستشعار اللمس. مثال صغير لكنه توضيحي لطرفية micro:bit واحدة تحتاج للتنازل صراحة عن مورد مشترك لأخرى.

مرجع بروتوكول BLE

Nordic UART عبر BLE، بحد MTU 20 بايت مع تجزئة تلقائية، فلتر اسم الجهاز BBC micro:bit. عينة تمثيلية من مجموعة الأوامر الكاملة (انظر README للجدول الكامل لنحو 30 أمر OTHER:*):

الاتجاهالرسالةالمعنى
micro:bit ← المتصفحTEMP:<C>, LIGHT:<0-255>, SOUND:<0-255>, ACC:<x>,<y>,<z>, COMPASS:<0-360>قياس عن بُعد حي، كل منها مُقيَّد التردد ويُرسل فقط عند التغيير.
micro:bit ← المتصفحLEDS:<r0>,<r1>,<r2>,<r3>,<r4>حالة LED الفعلية (كل صف 0–31)، تبقي النموذج ثلاثي الأبعاد متزامنًا.

السمات & اللغات

أربع سمات مرئية (Stealth الداكنة الافتراضية، Neon سايبربانك، Arctic الفاتحة، Blaze الفاتحة الدافئة) مبنية على أكثر من 30 خاصية CSS مخصصة، محفوظة في localStorage. ترجمة كاملة للواجهة إلى الإنجليزية/الفرنسية/العربية عبر lang.js، مع نفس العلم الجزائري الدقيق المستخدم في هذه المجموعة من التطبيقات للعربية ودعم التخطيط من اليمين إلى اليسار.

الحصول على الفيرموير

على عكس Bit-Bot وTalking Robot، لا يمتلك هذا المشروع بعد صفحة flash.html مخصصة للنسخ واللصق — يعيش الفيرموير مباشرة في makecode.ts في جذر المستودع، مع البروتوكول الكامل موثّقًا في تعليق ترويسته الخاص. افتحه على GitHub، انسخ المحتوى، والصقه في مشروع JavaScript جديد على makecode.microbit.org كما هو موصوف في خطوة بخطوة أعلاه.
