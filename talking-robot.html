This article covers Talking Robot, a single-page web robot that speaks typed text out loud, transcribes what it hears, animates 13 emotions, and can send words to a BBC micro:bit over Bluetooth — with no AI provider or account involved.

Overview

Talking Robot is the simpler, earlier sibling of Bit-Bot: no AI provider, no chat history, no accounts — just the browser's built-in Speech Synthesis (text→voice) and Speech Recognition (voice→text) APIs, an animated SVG robot face with 13 emotions, and an optional BBC micro:bit link over Web Bluetooth UART. Everything runs client-side; nothing is ever sent to a server.

The app is spread across a few files rather than one: index.html (markup + all app logic inline), styles.css, and makecode.ts (the companion micro:bit firmware source), plus a standalone flash.html for getting that firmware onto a board.

Quick start

  1. Open the live app in Chrome or Edge.
  2. Type something in the text box and click Speak — the robot talks and its mouth animates.
  3. Click Listen, allow the microphone, and talk — your words appear in the box.

Make it talk

Type text, pick a language and a voice under Voice & Language, then click Speak (or press Ctrl/Cmd+Enter). Rate and pitch sliders adjust delivery; a Random voice each speak option picks a different installed voice every time for variety.

Make it listen

Click Listen and allow the microphone. Two modes:

  • Single-shot (default) — captures one utterance, then stops.
  • Continuous listening (hands-free) — keeps restarting automatically after each phrase, showing interim text live as you talk.

Auto speak after listening makes the robot immediately repeat back what it heard.

Emotions

Thirteen emotion buttons under the robot face — Neutral, Happy, Sad, Angry, Angry+, Surprised, Laugh, Silly, Scared, Party, Robot, Nerdy, Sleepy — each instantly swap the eyes/eyebrows/mouth/cheeks CSS state. If a micro:bit is connected, the same emotion is sent to it as an EMO:<name> command.

Connecting a micro:bit

Click Connect under BLE micro:bit (UART) and pick your board. Once paired, the robot automatically sends every spoken/typed/heard word to the micro:bit as one token per line, tagged with a syllable count (e.g. 3_elephant), and the micro:bit acknowledges each with OK 3_elephant back over the same UART link — visible in the on-page Log.

Listen and Bluetooth both require a secure context: https:// or localhost, not a bare file:/// page.

Getting the firmware code

flash.html fetches the current makecode.ts and shows it with a one-tap Copy micro:bit Code button, plus the steps to paste it into makecode.microbit.org, add the bluetooth extension, and flash. It also links straight to an already-programmed shared MakeCode project for anyone who'd rather skip the copy-paste entirely. It's linked from a Get Firmware Code button under Project Links on the main page.

Languages & translation system

Unlike Bit-Bot, this app originally had no UI translation at all — only the speech language dropdown was multilingual. It now has a full I18N object (English/French/Arabic) with a flag-based switcher in the header, covering every button, card, hint, and the ~50 dynamic log/status messages, with right-to-left layout for Arabic. The language choice is stored under its own localStorage key, separate from Bit-Bot's, since both apps share the abourdim.github.io origin.

In-app Help

A ❓ button in the header opens a modal covering Make it talk, Make it listen, Change emotions, Connect a micro:bit, and Tips — translated the same as the rest of the UI, closable via × / Escape / clicking outside.

Troubleshooting

SymptomCause / fix
Listen does nothingUse Chrome/Edge, allow the microphone, and open via http://localhost or https:// — not file:///.
No Arabic voice availableThe OS needs an Arabic text-to-speech voice installed; the app logs a specific warning and falls back to another voice if none is found.
Bluetooth connect failsNeeds HTTPS/localhost and a browser with Web Bluetooth (Chrome/Edge). The micro:bit must be advertising and in range.
micro:bit never sends an ACKReflash with the current code from flash.html and make sure the bluetooth extension is added in MakeCode.
