نظرة عامة

كان كلا الجهازين على نفس الشبكة المحلية (LAN)، وهو أمر مطلوب لهذا الإعداد (لا حاجة لإعادة توجيه المنافذ أو VPN). يتحدث كل من Ubuntu (عبر Samba) وWindows (بشكل أصلي) بروتوكول SMB/CIFS، لذا يمكن لكل نظام تشغيل أن يعمل كخادم ملفات وكعميل للآخر في آن واحد — دون الحاجة لأي برنامج طرف ثالث.

ملاحظة: استبدل عناوين IP وأسماء المستخدمين وأسماء المشاركات أدناه بقيم أجهزتك الخاصة.

مشاركة مجلد Ubuntu مع Windows

الهدف: جعل مجلد Ubuntu (مثل الدليل الرئيسي) يظهر كمحرك أقراص شبكي على Windows.

على Ubuntu — تثبيت & تهيئة Samba

ثبّت Samba (تخطَّ هذه الخطوة إذا كانت مثبتة بالفعل):

sudo apt-get update
sudo apt-get install -y samba

أضف تعريف مشاركة إلى /etc/samba/smb.conf:

sudo tee -a /etc/samba/smb.conf > /dev/null <<'EOF'

[home_abdelhak]
   comment = Abdelhak Home Folder
   path = /home/abdelhak
   browseable = yes
   read only = no
   guest ok = no
   valid users = abdelhak
   create mask = 0664
   directory mask = 0775
EOF

اضبط كلمة مرور Samba لمستخدم Linux الخاص بك (مخزن اعتماد منفصل عن كلمة مرور تسجيل الدخول الخاصة بك):

sudo smbpasswd -a abdelhak

أعد تشغيل خدمات Samba واسمح بها عبر جدار الحماية:

sudo systemctl restart smbd nmbd
sudo ufw allow samba          # فقط إذا كان ufw مفعّلًا

تأكد من أن Samba تبدأ تلقائيًا عند الإقلاع:

sudo systemctl enable smbd nmbd

على Windows — الاتصال بالمشاركة

افتح موجه الأوامر أو PowerShell واختبر الاتصال:

net use Z: \\192.168.1.78\home_abdelhak /user:abdelhak

أدخل كلمة مرور Samba عند المطالبة بها.

اجعل الربط دائمًا (يبقى بعد إعادة التشغيل، يعيد الاتصال تلقائيًا عند تسجيل الدخول):

net use Z: /delete
net use Z: \\192.168.1.78\home_abdelhak /user:abdelhak /persistent:yes

افتح مستكشف الملفات — يظهر محرك الأقراص تحت «هذا الجهاز» كـhome_abdelhak (Z:).

مشكلة معروفة: إذا أظهر المستكشف «impossible d'accéder» (تعذر الوصول) لكن net use يعمل بشكل جيد، فعادة يكون السبب أن ملف تعريف شبكة Windows مضبوط على عام بدلًا من خاص. تُقيّد ملفات التعريف العامة تصفح SMB في المستكشف رغم أن الاتصالات المباشرة لا تزال تعمل. أصلح ذلك تحت الإعدادات → الشبكة & الإنترنت → اتصالك → نوع ملف تعريف الشبكة → خاص.

مشاركة مجلد Windows مع Ubuntu

الهدف: تحميل (mount) مجلد Windows (مثل ملف تعريف المستخدم) كدليل محلي على Ubuntu.

على Windows — تفعيل المشاركة

تأكد من تفعيل اكتشاف الشبكة & مشاركة الملفات: الإعدادات → الشبكة & الإنترنت → إعدادات الشبكة المتقدمة → إعدادات المشاركة المتقدمة، بدّل اكتشاف الشبكة ومشاركة الملفات والطابعات إلى تشغيل لملف التعريف الخاص.

انقر بزر الفأرة الأيمن على المجلد المراد مشاركته (مثل C:\Users\Win10) → خصائص → تبويب مشاركة → مشاركة متقدمة. حدّد «مشاركة هذا المجلد»، أعطه اسم مشاركة (مثل Win10). انقر على الأذونات → امنح مستخدمك التحكم الكامل → موافق → موافق → إغلاق.

تحقق من PowerShell:

net share

على Ubuntu — تحميل المشاركة

ثبّت أدوات عميل CIFS:

sudo apt-get install -y cifs-utils

أنشئ نقطة تحميل واختبرها:

sudo mkdir -p /mnt/win10share
sudo mount -t cifs //192.168.1.54/Win10 /mnt/win10share \
  -o username=Win10,uid=$(id -u),gid=$(id -g)

أدخل كلمة مرور حساب Windows عند المطالبة بها، ثم أكّد بـ:

ls /mnt/win10share

اجعله دائمًا باستخدام ملف اعتماد (أكثر أمانًا من كلمة مرور نصية واضحة في /etc/fstab، والتي يمكن لأي شخص قراءتها):

sudo mkdir -p /etc/samba/creds
sudo nano /etc/samba/creds/win10share

أضف:

username=Win10
password=YOUR_WINDOWS_PASSWORD

قيّد أذونات الملف:

sudo chmod 600 /etc/samba/creds/win10share

أضف إدخال تحميل تلقائي دائم إلى /etc/fstab:

echo "//192.168.1.54/Win10 /mnt/win10share cifs credentials=/etc/samba/creds/win10share,uid=$(id -u),gid=$(id -g),iocharset=utf8,x-systemd.automount,x-systemd.requires=network-online.target,_netdev 0 0" | sudo tee -a /etc/fstab

أعد التحميل واختبر:

sudo systemctl daemon-reload
sudo mount -a
ls /mnt/win10share
لماذا x-systemd.automount + _netdev؟ تُحمّل هذه الخيارات المشاركة عند الطلب بمجرد جاهزية الشبكة، بدلًا من إيقاف الإقلاع إذا كان جهاز Windows مطفأً أو غير قابل للوصول.

تصفح المشاركات من كل مدير ملفات

من Ubuntu (Nautilus / «الملفات»)

بمجرد التحميل، تصفحه مثل أي مجلد محلي: افتح الملفات، اضغط Ctrl+L، اكتب /mnt/win10share، اضغط Enter. اختياريًا، اسحب المجلد إلى الشريط الجانبي لإضافته كإشارة مرجعية.

بدلًا من ذلك، اتصل مباشرة عبر الشبكة بدون تحميل fstab: اضغط Ctrl+L وأدخل smb://192.168.1.54/Win10 — هذا يطلب بيانات الاعتماد عبر مربع حوار رسومي.

من Windows (مستكشف الملفات)

يظهر محرك الأقراص المرتبط تلقائيًا تحت هذا الجهاز بمجرد إعداده بـ/persistent:yes. يمكنك أيضًا كتابة مسار UNC مباشرة في شريط العنوان: \\192.168.1.78\home_abdelhak.
