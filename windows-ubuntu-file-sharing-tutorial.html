Partage de fichiers entre Ubuntu & Windows 11

Cet article documente une procédure étape par étape pour mettre en place un partage de fichiers bidirectionnel sur un réseau local.

Aperçu

Les deux machines étaient sur le même réseau local (LAN), ce qui est requis pour cette configuration (aucune redirection de port ni VPN nécessaire). Ubuntu (via Samba) et Windows (nativement) parlent tous deux le protocole SMB/CIFS, donc chaque OS peut agir à la fois comme serveur de fichiers et comme client de l'autre — aucun logiciel tiers requis.

Remarque : remplacez les adresses IP, noms d'utilisateur, et noms de partage ci-dessous par les valeurs de vos propres machines.

Partager un dossier Ubuntu vers Windows

Objectif : faire apparaître un dossier Ubuntu (par ex. le répertoire personnel) comme un lecteur réseau sur Windows.

Sur Ubuntu — installer & configurer Samba

Installez Samba (passez cette étape s'il est déjà installé) :

sudo apt-get update
sudo apt-get install -y samba

Ajoutez une définition de partage à /etc/samba/smb.conf :

sudo tee -a /etc/samba/smb.conf > /dev/null <<'EOF'

[home_abdelhak]
   comment = Abdelhak Home Folder
   path = /home/abdelhak
   browseable = yes
   read only = no
   guest ok = no
   valid users = abdelhak
   create mask = 0664
   directory mask = 0775
EOF

Définissez un mot de passe Samba pour votre utilisateur Linux (stockage d'identifiants distinct de votre mot de passe de connexion) :

sudo smbpasswd -a abdelhak

Redémarrez les services Samba et autorisez-les à travers le pare-feu :

sudo systemctl restart smbd nmbd
sudo ufw allow samba          # uniquement si ufw est actif

Assurez-vous que Samba démarre automatiquement au démarrage :

sudo systemctl enable smbd nmbd

Sur Windows — se connecter au partage

Ouvrez l'invite de commandes ou PowerShell et testez la connexion :

net use Z: \\192.168.1.78\home_abdelhak /user:abdelhak

Entrez le mot de passe Samba lorsque demandé.

Rendez le mappage permanent (survit à un redémarrage, se reconnecte automatiquement à la connexion) :

net use Z: /delete
net use Z: \\192.168.1.78\home_abdelhak /user:abdelhak /persistent:yes

Ouvrez l'Explorateur de fichiers — le lecteur apparaît sous « Ce PC » comme home_abdelhak (Z:).

Problème connu : si l'Explorateur affiche « impossible d'accéder » mais que net use fonctionne bien, c'est généralement parce que le profil réseau Windows est défini sur Public au lieu de Privé. Les profils publics restreignent la navigation SMB dans l'Explorateur même si les connexions directes fonctionnent toujours. Corrigez cela sous Paramètres → Réseau & Internet → votre connexion → Type de profil réseau → Privé.

Partager un dossier Windows vers Ubuntu

Objectif : monter un dossier Windows (par ex. le profil utilisateur) comme répertoire local sur Ubuntu.

Sur Windows — activer le partage

Confirmez que la découverte réseau & le partage de fichiers sont activés : Paramètres → Réseau & Internet → Paramètres réseau avancés → Paramètres de partage avancés, basculez Découverte réseau et Partage de fichiers et d'imprimantes sur Activé pour le profil Privé.

Faites un clic droit sur le dossier à partager (par ex. C:\Users\Win10) → Propriétés → onglet Partage → Partage avancé. Cochez « Partager ce dossier », donnez-lui un nom de partage (par ex. Win10). Cliquez sur Autorisations → accordez à votre utilisateur le Contrôle total → OK → OK → Fermer.

Vérifiez depuis PowerShell :

net share

Sur Ubuntu — monter le partage

Installez les outils client CIFS :

sudo apt-get install -y cifs-utils

Créez un point de montage et testez-le :

sudo mkdir -p /mnt/win10share
sudo mount -t cifs //192.168.1.54/Win10 /mnt/win10share \
  -o username=Win10,uid=$(id -u),gid=$(id -g)

Entrez le mot de passe du compte Windows lorsque demandé, puis confirmez avec :

ls /mnt/win10share

Rendez-le permanent en utilisant un fichier d'identifiants (plus sûr qu'un mot de passe en clair dans /etc/fstab, qui est lisible par tous) :

sudo mkdir -p /etc/samba/creds
sudo nano /etc/samba/creds/win10share

Ajoutez :

username=Win10
password=YOUR_WINDOWS_PASSWORD

Verrouillez les permissions du fichier :

sudo chmod 600 /etc/samba/creds/win10share

Ajoutez une entrée de montage automatique permanente à /etc/fstab :

echo "//192.168.1.54/Win10 /mnt/win10share cifs credentials=/etc/samba/creds/win10share,uid=$(id -u),gid=$(id -g),iocharset=utf8,x-systemd.automount,x-systemd.requires=network-online.target,_netdev 0 0" | sudo tee -a /etc/fstab

Rechargez et testez :

sudo systemctl daemon-reload
sudo mount -a
ls /mnt/win10share
Pourquoi x-systemd.automount + _netdev ? Ces options montent le partage à la demande une fois le réseau prêt, au lieu de bloquer le démarrage si le PC Windows se trouve éteint ou inaccessible.

Parcourir les partages depuis chaque gestionnaire de fichiers

Depuis Ubuntu (Nautilus / « Fichiers »)

Une fois monté, parcourez-le comme n'importe quel dossier local : ouvrez Fichiers, appuyez sur Ctrl+L, tapez /mnt/win10share, appuyez sur Entrée. Vous pouvez éventuellement glisser le dossier dans la barre latérale pour le mettre en signet.

Alternativement, connectez-vous en direct sur le réseau sans le montage fstab : appuyez sur Ctrl+L et entrez smb://192.168.1.54/Win10 — cela demande les identifiants via une boîte de dialogue graphique.

Depuis Windows (Explorateur de fichiers)

Le lecteur mappé apparaît automatiquement sous Ce PC une fois configuré avec /persistent:yes. Vous pouvez aussi saisir le chemin UNC directement dans la barre d'adresse : \\192.168.1.78\home_abdelhak.

Dépannage

SymptômeCause probableSolution
L'Explorateur ne peut pas parcourir le partage, mais net use fonctionne Profil réseau défini sur Public Basculez vers le profil Privé dans les paramètres réseau Windows
Connexion RDP « connexion perdue » immédiatement Port 3389 bloqué par le pare-feu Windows, ou RDP pas réellement activé Vérifiez le pare-feu → autorisez le Bureau à distance ; confirmez que le bouton bascule est activé dans Paramètres → Système → Bureau à distance
Deux serveurs RDP entrent en conflit sur Ubuntu (xrdp vs. GNOME Remote Desktop) Les deux essaient de se lier au port 3389 Désactivez celui non utilisé : sudo systemctl disable --now xrdp
mount.cifs: command not found Paquet manquant sudo apt-get install -y cifs-utils

Statut : partage Ubuntu → Windows terminé   partage Windows → Ubuntu terminé   Contrôle d'écran RDP en attente / partiel
