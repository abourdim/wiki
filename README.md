# Wiki

Personal notes and how-to guides.

Every article is available in French (default), English, and Arabic (RTL). The bare filename is the French version; add `-en` or `-ar` for the other languages (e.g. `bit-rxy.html` = French, `bit-rxy-en.html` = English, `bit-rxy-ar.html` = Arabic). Each page has a language switcher in its masthead.
