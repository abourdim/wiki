  • VideoCar — Enhanced firmware and web control page for the keyestudio ESP32-CAM Video Smart Car: joystick control, failsafe, live Vision overlays, autonomous Follow-me/Line/Colour-chase modes. complete
  • Bit-Bot — AI robot companion for kids: voice chat with a choice of AI providers, 12 personalities, AI-powered mini-games, and an optional BBC micro:bit link over Bluetooth. Full EN/FR/AR translation. complete
  • Talking Robot — Browser speech & emotion robot: text-to-speech, speech recognition, 13 animated emotions, and an optional BBC micro:bit link over Bluetooth. No AI provider, fully offline. complete
  • micro:bit Playground — 8-tab BLE control panel and sensor dashboard for the BBC micro:bit V2: live sensor graphing, servo control, 5 interactive 3D robot models, and a 30+ command firmware protocol. Full EN/FR/AR translation. complete
  • Micro:bit Remote Builder (bit-rxy) — Drag-and-drop BLE remote-control builder: design a layout from 12 widget types and it generates matching MakeCode firmware automatically, with one-click flashing over Bluetooth Partial Flashing Service or WebUSB. complete
  • Keyes 4WD Mecanum Remote — Single-page Web Bluetooth remote for the Keyestudio V2 mecanum robot: 8-way pad, servo, headlights and telemetry, with no build step and no server. Documents three silent traps: inverted UART UUIDs, the wrong MakeCode extension, and the LED matrix stealing the sensor pins. complete
  • DFRobot Rover — Two-servo rover on the DFRobot micro:Driver board: trim stored in the robot’s own flash, a sweeping sensor head, and a screen that does self-test, face or radar. Documents the invisible settings dependency and the NeoPixel/Bluetooth clash. done
  • Keyes 4WD Mecanum RXY — Widget version of the same robot, descended from bit-rxy: 31 widgets described by the firmware itself, a one-byte bitmask mecanum pad, NeoPixel strip, autonomous Line and Avoid modes, and the micro:bit's own sensors. complete
  • ESP32-RXY — ESP32 firmware that impersonates a BBC micro:bit's BLE UART protocol, so the unmodified rxy web app can connect to a plain ESP32-C3 and drive widgets exactly as it would a real micro:bit. complete
  • WDIY Robot (esp32c3_super_mini_robot-bit-rxy) — Small differential-drive robot, converted from the paid RemoteXY app to bit-rxy's BLE protocol by following the ESP32-RXY pattern: joystick, D-Pad, horn, live speed/distance/battery gauges, and sound feedback. complete
  • WDIY Robot — original RemoteXY version (esp32c3_super_mini_robot_remotexy) — The original firmware for the same robot, driven by the commercial RemoteXY app and its visual GUI editor. Predates and untouched by the bit-rxy conversion above. complete
  • rxy-web — The universal Bluetooth remote for rxy robots: it knows no robot in advance, it asks whichever one it just found to send its own interface, then draws it. 20 widget types, a layout cache, and a radar fed by two values the robot already sends. complete
  • Robot MV — A port of bit-rxy onto a different carrier board: same modules, every pin moved. Adds a panning sonar head, and with it a radar that draws the room instead of flashing a number. complete
  • Servo-Sonar — A reduced version of bit-rxy: two drive servos, one distance sensor, nothing else. Each wheel's trim is set from the app while driving and kept in memory — no more reflashing to straighten a robot. complete
